# pairwise-os2

## 题面（可直接粘贴）

用 OS/2 与 hhea 表计算文本排版的行高、基线与逐字形步进。约束：行高等于 ascent+descent+lineGap；缺表时回退到 head 表且结果可解释；版本越界要报错；连续排版 1 万个字形不累积浮点漂移（误差 ≤1e-9）；并发排版同一字体安全；既有解析结果不变；不得新增依赖。验收：python -m pytest tests -q -k os2。改动限 2 到 3 个文件，增量构建加测试不超过 30 秒。不得改动既有测试与既有行为。交付给命令、输出、耗时三行自测证据。

## 边界要求（评审侧隐藏用例判分，不在可见测试里）

- 版本 0 与 1 字段偏移不同
- 缺表时 weight 返回 None
- 非法字重范围
- 旧解析结果不变
- 并发解析同一字体

## 运行方式

```bash
python -m pytest tests -q
```

初始 15 failed。可见测试只覆盖主功能（3 分线），通过不代表满分。
